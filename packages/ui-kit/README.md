# @reddb-io/ui-kit

Temporary compatibility facade for historical RedDB component and token APIs.
All implementation belongs to the pinned Design System. New applications use
canonical Base/App/Data components; existing imports retain their behavior.

The equivalent compatibility root is
`@reddb-io/design-system/hosts/workspace/compat`, selected through pinned Sync.
The package includes exact DS source, assets, receipt and licenses without a
private-registry dependency. It is supported throughout 0.8.x; removal requires
an announced breaking release no earlier than 0.9.0.
